# 🧠 Фундаментальные Навыки и Правила (nextjs-starter)

Этот файл дополняет правила из `CLAUDE.md` и определяет "внутреннюю логику" работы с этим шаблоном. Любой агент, работающий с этим проектом, должен следовать этим принципам.

---

## 1. Дизайн-код: "Сероцветный Лакшери" (Quiet Luxury)

Это ключевой визуальный навык проекта. Мы стремимся к эстетике "тихой роскоши".

- **Правило "Скрытых Акцентов":** Функциональные цвета (Emerald для успеха, Amber для роботов, Violet для аналитики) **никогда** не должны быть кричащими по умолчанию. 
- **Реализация:**
    - По умолчанию элементы нейтрально-серые (`neutral-500`).
    - Цвет проявляется **только при взаимодействии** (hover).
    - Вместо плотных заливок используем тонкие границы (`border-neutral-800/50`) и легкое свечение (`shadow`, `glow`).
- **Стек Спирали:** Все удачные темы фиксируются в `STYLE_BANK.md` и затем переносятся в `globals.css`.

## 2. Протокол "Локальной Безопасности" (Local-First)

Мы не используем Vercel как компилятор или отладчик.

- **Правило Build-Lock:** Запрещено пушить код в `main` или `dev` без успешного прохождения команды `npm run pre-deploy` локально.
- **Приоритет ошибок:** Если возникла ошибка `EPERM` (macOS), не пытайтесь обойти её через `sudo`. Используйте `fix-permissions.sh` для восстановления прав доступа к `.env.local` и `node_modules`.

### 3. Неубиваемый AI (Unkillable AI)
- **Gemini Stack**: Использование двух Tier 1 ключей (Основной + Резервный).
- **OpenRouter Fallback**: Если Gemini недоступен, автоматическое переключение на OpenRouter (DeepSeek/Qwen).
- **Диагностика**: Периодический запуск `npm run go-to-stars` для проверки "боезапаса".

### 4. Прикладной Интеллект (Product-First Extraction)
- **Никакой воды**: Игнорировать общие новости о стартапах, стримах, встречах и "разговорах о рынке".
- **Атомарность**: Если в источнике (статье/видео) несколько проектов, AI обязан создать **отдельную запись для каждого**. Одна запись = Одна прикладная идея.
- **Цель**: Каждая карточка в ленте должна быть готова к "клонированию" или использованию в "Блендере Идей".

## 5. Гигиена Окружения (Environment Integrity)

- **Env-валидация:** Перед запуском `dev` всегда выполняется `scripts/validate-env.mjs`. 
- **Правило соответствия:** Если добавляется новая секретная переменная, она **обязана** появиться в `.env.template` с описанием.

## 4. Архитектура "Unkillable AI"

Проект строится на отказоустойчивости ИИ-сервисов.

- **Навык каскада:** При реализации AI-функций всегда закладывать fallback-логику (Cascade). Пример: `Gemini Pro` -> `Gemini Flash` -> `Moonshot/OpenRouter`.
- **Локализация:** Все ответы AI и интерфейсные строки должны быть на **русском языке** по умолчанию, если не указано иное.

## 5. Работа с Базой Данных (Supabase)

- **SQL-First:** Сложные изменения схемы сначала описываются в `scripts/*.sql` для истории, а затем применяются через Dashboard.
- **Связи:** Любая новая сущность должна иметь четко определенные constraints (foreign keys, non-null), чтобы избежать "сиротских" данных.

---

> [!IMPORTANT]
> Эти правила являются фундаментальными. Отклонение от них ведет к деградации качества продукта.
